# Hoang Van Phi

Android developer building PiperOS Tool and its on-device Linux runtime.

## PiperOS

| Project | Purpose |
| --- | --- |
| [PiperOSTool-Android](https://github.com/Phi574/PiperOSTool-Android) | Android app with browser, media, device utilities and terminal UI |
| [Piperos_termux](https://github.com/Phi574/Piperos_termux) | GPLv3 bootstrap, package builds and APT repository for the PiperOS terminal |
| [PiperOSTool-PC](https://github.com/Phi574/PiperOSTool-PC) | Optional module release metadata |
| [module_piper-os-tool](https://github.com/Phi574/module_piper-os-tool) | Optional module release metadata |

PiperOS runtime packages target `com.piper.os.tool` and are built separately
for `arm64-v8a`, `armeabi-v7a` and `x86_64`.
