## PiperOS

| Project | Purpose |
| --- | --- |
| [PiperOSTool-Android](https://github.com/Phi574/PiperOSTool-Android) | Android app with browser, media, device utilities and terminal UI |

| [module_piper-os-tool](https://github.com/Phi574/module_piper-os-tool) | Optional module release metadata · On-device LLM modules (`.litertlm`): [gemma-4-E4B-it](https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm), [gemma-4-E2B-it](https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm), [gemma-3n-E2B-it](https://huggingface.co/google/gemma-3n-E2B-it-litert-lm), [gemma-3n-E4B-it](https://huggingface.co/google/gemma-3n-E4B-it-litert-lm), [Gemma3-1B-IT](https://huggingface.co/litert-community/Gemma3-1B-IT) |
| [data_AI](https://github.com/Phi574/data_AI) | AI assistant app data: prompts, memory schema, datasets, evals, docs |
